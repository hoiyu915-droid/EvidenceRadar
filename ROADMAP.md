# Roadmap

EvidenceRadar is maintained incrementally. Priorities are ordered by evidence-governance risk and reproducibility rather than fixed dates.

## Near term

- Publish the protocol, schemas, examples, validators, and licensing boundaries as a coherent public release.
- Add deterministic checks for licensing exclusions, artifact consistency, and state migration.
- Provide a minimal reproducible ChatGPT Work setup and sample run.
- Tag protocol and schema releases with compatibility notes.

## Later

- Add contributor fixtures for additional authoritative source surfaces.
- Record public integrations and downstream use without inventing adoption metrics.
- Improve correction, retraction, and version-transition handling.
- Stabilize protocol and schema compatibility for a 1.0 release.

Roadmap items are proposals, not promises. Material changes should begin with an issue and follow `CONTRIBUTING.md`.
