# Contributing to EvidenceRadar

Contributions are welcome through GitHub issues and pull requests.

## Contribution requirements

1. Keep each change focused and describe the research-governance behavior affected.
2. Preserve the distinction between discovery, event verification, evidence support, and report delivery.
3. Add or update schemas, examples, tests, and documentation when a contract changes.
4. Run the repository's documented validators and relevant tests.
5. Use primary or authoritative sources for factual claims and retain locators.
6. Do not commit API keys, credentials, private data, publisher PDFs, paywalled full text, or raw article dumps.
7. Do not represent search snippets, metadata freshness, or an inaccessible source as verified evidence.

## Review and maintenance

Maintainers review correctness, provenance, licensing, backward compatibility, source coverage, and failure behavior. Passing automated checks is necessary but does not itself authorize a merge.

AI-assisted contributions are accepted. Contributors remain responsible for checking generated changes, citations, licenses, and claims, and should disclose material AI assistance in the pull request.

By contributing code or executable workflow material, you agree that it is licensed under Apache-2.0. By contributing original documentation or research-summary content, you agree that your contribution is licensed under CC BY 4.0 unless a file states otherwise.
